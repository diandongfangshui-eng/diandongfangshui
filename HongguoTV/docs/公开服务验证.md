# 红果公开网站服务验证

验证日期：2026-10-31（Asia/Shanghai）。本报告是实际 HTTP 取回结果，区别于 APK 静态分析。没有使用登录账号、没有进行电视真机播放验收。

## 已验证的真实目录

GET https://hongguoduanju.com/ 返回 HTTP 200、约188KB HTML；脚本 `_ROUTER_DATA = ...` 的 loaderData.page.homeSections 内含 tab_type、tab_name、video_list。每条数据包含 series_id、series_title、series_cover、series_intro、episode_cnt、category_list、genre、rank 等。PublicWebsiteRepository 从原站直接读取该 JSON，不依赖电脑或 NAS，不包含演示片单。

GET https://hongguoduanju.com/category/real-drama 返回 HTTP 200、约274KB。loaderData["category_$"] 提供 selectorList（题材/筛选项）与 recommendList（24部真实剧目），pagination={total:800,pageNum:1,pageSize:24,totalPages:34}。适配器 category(route,page) 第一页省略查询参数（?page=1 会301跳转canonical路径），第二页发送 ?page=2。已实际验证第二页 pagination.pageNum=2，每页24条；第一页首ID 7699683909419666457，第二页首ID 7697167229489531966，结果不同。初次Java网络测试发现301问题，已修复并重新验证通过。

GET https://hongguoduanju.com/rank/hot-drama 返回 HTTP 200，但 loaderData["rank_hot-drama/page"].content={}。因此当前 ranking() 仅使用首页 homeSections 中 tab_type=all 的9条真实热播短剧，不能声称是完整独立排行榜接口。首页返回集数、标签、排行号不代表存在原生媒体播放许可。

## 真实详情与完整分集ID

GET https://hongguoduanju.com/detail?series_id=7690961604636052505 返回 HTTP 200、约564KB。loaderData.detail_page.seriesDetail 含 series_name、series_intro、celebrities、tags、series_episode_info、vid_list。

实测样本 episode_cnt=46、accessible_episode_cnt=3，vid_list 含46个ID。首集7690963410778868761，末集7690963495944211481。适配器保留实际 vid_list 顺序并生成第1至46集目录；标题序号是本地按返回顺序展示，不是服务器返回的独立集标题。当前通用 Drama 模型上限已提高至2000集；适配器不再按300截断，超过模型上限会明确拒绝。

列表卡片未返回分集ID时，模型保留总集数并只放明确标记“加载官方分集目录”的占位条目；详情必须重新取实际ID，不得把占位当成真实分集。

## 播放限制的实际证据

GET https://hongguoduanju.com/player/7690961604636052505 返回 HTTP 200、约243KB。loaderData["player_(series_id)/page"] 明确返回 protectedPlayback=true，videoList={}。publicVideoSeo.available=true，但只含 seriesId、itemId、posterUrl、durationSeconds=108.331、width=360、height=640，没有视频 URL。

详情HTML仅提供第1集 /player/{series_id} 和第2、3集 /player/{series_id}/{item_id} 链接。可交由官方网站在 WebView 内自行处理其公开播放流程；本次未确认其实际解码成功，也未验证后续剧集。无需或不得把 publicVideoSeo.available 理解为原生播放器已授权。

早期仅检查SSR不完整，后续已追踪正常前端POST流程并取得加密播放模型，见下文更新。当前 Media3 适配器没有专用加密SDK支持，因此未将加密DASH地址当普通MP4播放。账号、凭证及跨设备进度同步仍未接入。

## 实现与验证范围

PublicWebsiteRepository 实现 CatalogRepository、SearchRepository、SeriesRepository、PlaybackResolver、AuthenticationProvider；网络连接超时15秒，读取超时20秒，响应大小4MB上限，HTTP错误/缺失SSR字段均报错。

app/src/test/resources/public-home.html 与 public-detail.html 是本次实际响应中摘取的SSR业务字段，移除了请求遥测、评论等无关字段；不包含账号令牌或媒体URL。PublicWebsiteRepositoryTest 验证首页字段映射、46集ID完整性、明确拒绝受保护播放及不合法页面处理。构建代理已报告本轮20项自动测试通过；最终构建结果以交付说明为准。

原始HTTP响应保存在工作目录 work/public-*.html，JSON提取结果 work/public-*-data.json，属于调查中间材料。以上为抓取当时动态响应，原站可能调整结构或访问策略。

## 更新：真实加密播放模型与SDK限制

官网公开chunk 8.53d1576b05.js 中 resolveProtectedOptions 正常发起：

```
POST https://hongguoduanju.com/api/video/protected/play-info
Content-Type: application/json
{"series_id":"7690961604636052505","item_id":"7690963410778868761","definition":"720p"}
```

实测第一、二集均HTTP200、base_resp.StatusCode=0；play_info返回vid、main_url、backup_url、player_access_key、kid、format=dash、codec_type=h264、definition=720p、width=720、height=1280、audio、init_range/index_range、expires_at。第一集有效期示例1793457924。这里只验证模型获取成功，没有完成视频解码验收。早期仅SSR“不含媒体URL”的观察成立，但不能推断整个公开前端不存在媒体请求。

脱敏结构见《公开播放模型样本_脱敏.json》。原始响应仅存调查临时目录work/protected-play*.json，不应上传GitHub或打包交付，其中含短期媒体URL与播放密钥材料。

JS将模型传入DASHPlugin，设置secretKey=player_access_key、encrypt=true、useEME=false、useUnionInfoDRM=false，通过专用EncryptedDashPlayer处理；不是服务器提供ClearKey许可，也未证实可直接接入Media3标准Widevine/ClearKey。未自行提取/实现私有解密。

官网8.js的wh模块依赖zg.js中的Nh/EncryptedDashPlayer，属于官网打包专用插件；未找到该专用插件的独立开源许可。基础[xgplayer项目](https://github.com/bytedance/xgplayer)采用MIT，但不能据此断言官网专用加密插件也可复制分发。

火山官方提供正式VePlayer SDK集成路径：[播放DASH视频](https://docs.volcengine.com/docs/video-on-demand/web-player-dash-playback?lang=zh)说明通过业务服务端签发PlayAuthToken及DASHPlugin配置接入。[SDK常见问题](https://docs.volcengine.com/docs/video_on_demand/PlayerSDKFAQ?lang=zh)搜索索引明确自1.11.0起需要License；该条应在申请实际SDK前进一步核对当前账户条款。没有证据表明申请通用SDK License就会自动获得红果内容播放授权。

## 标准WebView具体兼容限制

官网8.js中xm模块的 encrypted_browser_allowlist 为safari/chrome/edge/baidu；浏览器分类代码明确将含wv标记的Android WebView归为unknown，并结合服务端req.encryptedBrowserAllowed决定支持。标准WebView可能被官方拒绝加密播放，即使设备具有MSE。不能通过伪装UA把浏览器许可限制说成已解决。

现有做法是加载官方页面，让官方自己的组件管理模型、密钥、有效期和播放权限；可在页面允许时控制HTMLVideoElement的暂停、seek、speed、ended切集，但这不构成独立SDK授权。应优先在真实电视标准WebView测试；如官方拒绝该容器，需要官方支持的SDK/容器授权或用户在受支持浏览器访问。当前没有给自有页面复制官网插件/抽取key并绕过容器限制。
