# 接口与数据模型映射

本客户端采用官网公开SSR服务；下列路径和字段由2026-10-31实际HTTP及Java网络读取验证，区别于APK内部RPC。

| 用途 | 请求 | 返回节点 | 客户端映射 |
|---|---|---|---|
| 首页 | GET https://hongguoduanju.com/ | loaderData.page.homeSections[].video_list[] | series_id→Drama.id，series_title→title，series_cover→poster，series_intro→description，episode_cnt→总集数，category_list首项→genre |
| 热播 | 同首页 | homeSections中tab_type=all | 9条真实官网热播，不能当作App独立全榜 |
| 分类 | GET /category/real-drama；第2页起?page=N | loaderData.category_$.recommendList / pagination | 24条/页，按ID去重，保留剧集ID为字符串 |
| 详情 | GET /detail?series_id=ID | loaderData.detail_page.seriesDetail | series_name→title，celebrities→可用演员说明，vid_list→按原顺序的videoId列表 |
| 网页播放 | GET /player/SERIES_ID[/VIDEO_ID] | player页面数据 | protectedPlayback=true，videoList={}；交给官网WebView处理 |
| 关键词建议 | GET /api/search/suggestion?query=关键词 | suggestionList[].video_data | 已接入真实元数据，丢弃仅文字建议；完整/result仍403 |
| 账号 | 未获第三方授权 | 无 | 访客状态、不能跨设备同步 |

页面中 `_ROUTER_DATA = ...` 使用JSONTokener读取，不能执行不可信脚本文本。连接15秒、读取20秒、最大4MB，非200或结构变化明确报错。

首页没有实际分集ID，卡片只携总集数；详情再读取vid_list。无媒体URL时playback_url为空，不能将videoId拼成CDN地址。元数据可浏览、网页可访问、原生已授权是三种不同状态。

APK模型及调用链的证据见REA分析.md和REA原始证据.zip。主包com.dragon.read.rpc.model与seriessdk.com.dragon.read.saas.rpc.model存在同名请求，不能混用。video_model、mainUrl、backupUrl、playAuthToken、expireTime字段仅静态确认，尚未获得真实授权响应用于原生接入。

更新：POST /api/video/protected/play-info（series_id、item_id、definition）正常返回加密DASH模型及expires_at。不是ClearKey许可；本轮未将私有EncryptedDashPlayer或密钥复制到应用。账号正常入口位于官方页面，App第三方授权仍未提供。
