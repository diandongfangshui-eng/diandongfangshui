# 0.8.0：片库扩展与分集权限实测

2026-11-01。版本0.8.0，Android TV 36模拟器；无红果账号登录。

## 本次修复

原首页只有33条推荐，不能作为完整片库。本版新增「全部片库」：真人剧、漫剧、AI剧，按服务返回的题材筛选；每页24条，上一页、下一页、末页、跳页和失败重试。实测三种目录各返回total=800、totalPage=34；真人第1/2页各24条，末页8条。类别间可能有重复，这不是2400部独立剧目，也不是原版App全量片库。分类的total字段由服务返回，未逐页下载核对800个唯一ID。

目录使用官网SSR响应，不需要手填JSON。详情显示真实简介、总集数、完整分集ID，非首页剧目可收藏和记录历史。片库进入详情后返回，保留当前分页和筛选。完整剧目元数据本地保存，临时播放链接和密钥不写入这些元数据。

## 请求与源码

- 首页：https://hongguoduanju.com/，homeSections.video_list。
- 分类：/category/real-drama、/category/comic-drama、/category/ai-drama；第1页不附page=1，其后?page=N。
- 题材：selectorList的真实ID映射子路径，例如/category/real-drama/urban。
- 分类解析：_ROUTER_DATA.loaderData中带recommendList的业务对象；读取分页、selectorList、视频元数据。
- 详情：/detail?series_id=ID，seriesDetail.episode_cnt/accessible_episode_cnt/vid_list。
- 播放：POST /api/video/protected/fallback-play-info，JSON仅item_id。成功后验证base_resp.StatusCode、HTTPS媒体地址与url_expire。
- BrowseActivity：电视分页目录及题材导航。
- PublicWebsiteRepository.catalogPage/parseCatalogPage：分页解析、路由校验、同页去重。
- MainActivity：详情跳转、本地收藏/历史元数据。
- PublicPlayerActivity：逐集请求、清除上集画面、错误显示和返回上一集。

## 三集限制的实际结果

《军需处长的账本》，series_id=7690961604636052505，目录46集，网页元数据accessible_episode_cnt=3。

正常未登录请求第3集：HTTP200，StatusCode=0，存在媒体地址。第4集：HTTP403，error=public_fallback_unavailable，没有媒体地址。原始成功响应含短期播放地址，未打包公开；脱敏结果见分集权限响应_脱敏.json。

旧版客户端用accessible_episode_cnt直接阻止后续请求。本版改为每次对真实分集ID发起正常播放请求，由当前服务响应决定可播与否。该字段只作显示提示，不推定账号权限。会话变化清除内存中的播放授权缓存；有效期到期重新请求。没有伪造成功响应或把拒绝分集标成已解锁。

TV模拟器实际操作：播放第3集→按下切到第4集→页面显示服务端HTTP403并清空旧媒体→按上返回第3集→视频继续播放。最新错误页明确「未能播放」，可确定重试或上下切集。自动连播也正常请求下一集，拒绝后停止，不跳过拒绝集继续枚举。

## 尚未解决

1. 当前官网未登录渠道对上述样本第4集明确拒绝；本版不能宣称全集播放完成。不能从这一个样本推断所有剧目或登录后的权限。
2. 红果App手机号验证码登录尚未接入此客户端。官网TV WebView未出现短信表单；原版App在ARM翻译模拟器崩溃，无真实账号动态证据。验证码仅由用户在官方界面输入。
3. 全站搜索result仍返回403，当前实现为官方关键词建议。
4. 加密DASH的SDK分支仍缺本应用有效License，未验收首帧；公开MP4主路径不需要该License。SDK许可不能替代内容权限。
5. 尚无物理电视或盒子验收，也没有登录后的全集播放验收。

因此，本次完成的是可用片库扩展、正确的逐集授权处理和APK更新；完整App目录、App账号登录、受限集播放仍未完成。不能把官网公开目录与完整App服务等同。
