# 果影 TV 0.4 电视端交互设计与验收说明

## 目的与适用范围

本次修改只作用于 `HongguoTV/` 下的非官方独立 Android TV 客户端。不修改用户上传的原版红果 APK 的签名、权限、登录或数字版权保护。
远程片单、局域网服务和红果公开官网仍是三种独立的内容来源；电视遥控器 UI 不代表取得平台内容许可。

## 页面结构

1. **首页**：左侧可滚动导航；右侧大幅横幅、立即播放/详情、短剧海报横排。每个可点击元素使用高亮焦点边框。
2. **分类 / 收藏 / 历史 / 搜索**：共用遥控器海报组件。搜索使用 Android TV 输入法。
3. **剧集详情**：标题、海报、剧情、继续播放、收藏、编号选集，进入详情后首选播放键聚焦。
4. **局域网片库**：配置自有服务后显示带封面的网格，确定键打开剧集，进入选集后聚焦第一集；菜单键返回搜索。
5. **红果官网**：WebView 加独立遥控光标。与真正触摸屏不同，手柄/遥控器的方向键移动光标、确定键模拟一次实际用户点击、频道上下键翻页。按菜单/返回键退出光标并回到顶部工具栏。视频能否加载取决于官网行为和 WebView 能力。
6. **播放器**：左右每次跳 10 秒、上下切集、确定键暂停/恢复、菜单键倍速。浮层在约 6.5 秒后隐藏并在下一次操作时出现。

## 验收矩阵（真机待测）

| 测试步骤 | 预期 |
|---|---|
| 720p/1080p 电视启动 | 左侧 8 项导航均可滚动选中 |
| 使用方向键移动到海报 | 显示红色焦点框、投影和轻微放大 |
| 在首页选择“剧情详情” | 进入详情且播放按钮获得焦点 |
| 在详情按返回键 | 回到上一层，并尽可能恢复之前海报焦点 |
| 进入搜索框 | 电视系统软键盘可输入；确定键提交 |
| 进入「红果官网片库」 | 页面显示官网，按菜单键进入顶部工具栏 |
| 点击「遥控光标」 | 出现红色十字光标，方向键移动、确定键点击 |
| 光标模式按频道上/下 | 页面滚动；菜单键退出光标 |
| 播放公开测试片段 | 6.5 秒后提示条隐藏，按方向键重新显示 |
| 无授权播放地址的剧集 | 只显示详情，不发起播放请求 |

## 安全边界

WebView 仅放行 `hongguoduanju.com` 及 `www.hongguoduanju.com` 的 HTTPS 顶级导航；不获取站点密码或 Cookie；遥控光标只响应用户按键，不自动点击或提取付费媒体。
